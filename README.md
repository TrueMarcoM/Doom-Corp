Clone the project to your machine.

Navigate to the client folder, and compile/run the DoomCorpApp program in your terminal.
Also, expand your terminal window to be at least 95 characters wide.

Mainly tested on bash shell.
```bash
javac DoomCorpApp.java
```
```bash
java DoomCorpApp
```

Active features: Account Creation.
